RunAsync(Action, CancellationToken)

Executes the specified action asynchronously, catching any exception that may occur.

public static Task<Result> RunAsync(Action action, CancellationToken token = default)

Parameters

action Action

The action to execute.

token CancellationToken

A CancellationToken that is passed to Run(Action, CancellationToken). If cancellation is requested before action begins executing, the task is canceled and an OperationCanceledException is propagated to the caller rather than wrapped in a failed Result. Once action has started, Run(Action, CancellationToken) cannot interrupt it; cancellation during execution is only observed if action itself cooperatively checks the token (e.g. via ThrowIfCancellationRequested()) and throws.

Returns

Task<Result>

A Task of Result representing the asynchronous operation.

Exceptions

ArgumentNullException

action is null.

OperationCanceledException

Cancellation was observed via token (either before action started, or because action itself observed the token and threw).

RunAsync<T>(Func<Task<T?>>, CancellationToken)

Executes the specified function, catching any exception that may occur.

public static Task<Result<T?>> RunAsync<T>(Func<Task<T?>> function, CancellationToken token = default)

Parameters

function Func<Task<T>>

The function to execute.

token CancellationToken

A CancellationToken that is checked before function is invoked. If cancellation is already requested, an OperationCanceledException is thrown without invoking function. The token is not threaded into function itself; if you need cancellation inside the function, capture the token in the lambda's closure. If function observes the token during execution (e.g. via Delay(int, CancellationToken)) and the resulting OperationCanceledException escapes, it is also propagated to the caller rather than wrapped in a failed Result<T>.

Returns

Task<Result<T>>

A Task of Result<T> representing the asynchronous operation.

Type Parameters

T

The return type of the function.

Exceptions

ArgumentNullException

function is null.

OperationCanceledException

token was already canceled when this method was called, or function observed cancellation during execution and let an OperationCanceledException escape.
