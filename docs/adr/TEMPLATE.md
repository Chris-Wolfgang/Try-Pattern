# NNNN — Short title in the imperative

- **Status**: Accepted
- **Date**: YYYY-MM-DD
- **PR / Issue**: #NNN (delete if retroactive)

## Context

What is the situation forcing a decision? Include the concrete facts
that are load-bearing: TFMs shipped, APIs in play, consumer expectations,
prior bugs or incidents. Include at least one alternative that a reader
might reach for first, so they can see why it doesn't win.

## Decision

State the choice, imperative voice. One paragraph or a short bulleted
list. No hedging.

## Consequences

The trade-offs. What we now cannot do, what future work has to remember,
what breaks if this decision is silently undone. Include the failure
mode explicitly — "if X changes without an ADR update, Y breaks in Z way."
